src Directory
=============

The `src` directory contains the main source code for the OpenCast repository 
object plugin in ILIAS. It is organized into several components, each with its 
own functionality and purpose.
We try to have as little dependencies between the components as possible to 
ensure modularity and maintainability. And we try to avaid ILIAS 
dependencies wherever possible.
